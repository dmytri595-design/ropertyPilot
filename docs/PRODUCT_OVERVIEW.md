# Product Overview

## Positioning
**PropertyPilot — AI Real Estate Listing Engine** is a working local-first prototype that turns one structured property record into multiple editable marketing outputs.

## Target customers
Real estate agencies, independent agents, property marketing teams, new-development sales teams, rental operators, vacation property managers, property investors and proptech platforms.

## Core outputs
1. Property Title
2. Full Listing Description
3. SEO Description
4. Facebook Ad
5. Instagram Caption
6. Short Listing Version
7. Buyer Email
8. Social Media Caption
9. Translations
10. Key Features / Highlights

## Product behavior
- Listing purpose can be set to sale, rent, short stay, or commercial lease; key marketing outputs reflect that choice.
- Seven templates influence copy positioning for luxury, residential, rental, commercial, new-development, vacation, and investor contexts.
- New users can load a fictional sample property to explore creation without entering private listing details.
- Local photo previews are compressed in the browser to reduce localStorage pressure; photos are not uploaded to a server.
- Draft / Ready / Published / Archived statuses are local workflow labels only. No external portal is contacted.

## Workflow
Dashboard → Create Property → Photo Workspace → Generate → Review & Edit → Translate → Export → Publish / Archive.

## Demo
Seeded fictional properties include Nordic Waterfront Residence, Modern City Center Apartment, Luxury Mountain Chalet, Contemporary Family Villa and Renovated Investment Apartment.

All demo data is fictional and not a claim about real inventory, revenue or market performance.

## Current stage
Working SaaS MVP / Pre-launch / Pre-revenue.

Production AI, image analysis, translation, authentication, backend storage and connected publishing systems are integration targets rather than current claims. The current AI and translation outputs are deterministic mock/local text, not live provider output.
