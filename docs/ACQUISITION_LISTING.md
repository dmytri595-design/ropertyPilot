# Acquisition Platform Submission Copy

## Product Name
PropertyPilot — AI Real Estate Listing Engine

## Tech Stack
HTML5, CSS3, Vanilla JavaScript, LocalStorage, GitHub Actions, GitHub Pages. Modular adapters for AI, image analysis, translation, storage, database, authentication, email and CRM/property portals.

## Description
PropertyPilot is a working browser-first, local-first prototype that turns one property record into a complete editable real-estate marketing package. Agents add property facts and photos, choose a listing purpose (sale, rent, short stay, or commercial lease), generate a listing title, full description, SEO copy, Facebook ad, Instagram caption, short listing, buyer email, social caption, translations and key highlights, then edit, copy, export and track local status.

Seven selectable templates influence copy positioning. A one-click fictional sample listing guides first-time reviewers. Local image previews are compressed in the browser and are not uploaded. The current AI, image analysis and translation layers are local/demo implementations. A buyer can connect production providers without rebuilding the product workflow.

## Problem solved
Agents repeatedly copy the same facts into portals, social channels, email and internal tools. PropertyPilot creates one property source of truth and reuses it across marketing formats.
